# Live news MCP servers with category, section or topic selection, and whether Bloomberg offers one

State as of 2026-10-29 (desk research only; nothing was installed, run or probed with an MCP client). Scenario: a Microsoft Foundry lab needs a real, third-party news MCP server that (a) exposes news by category, (b) is reachable as a remote streamable-HTTP or SSE endpoint, or failing that is open source and can be deployed unmodified to Azure, (c) is free or has a free tier, and (d) is maintained. Agent A is unrestricted, agent B is limited to a subset of categories, and the server itself cannot be changed.

Reading key. "Official" means published by the data owner (the vendor, publisher or wire service). "Community" means a third-party wrapper. "Hosted" means the owner or a platform runs the endpoint. "Single tool with a category parameter" means authorization has to inspect `tools/call` arguments (argument-level); "one tool per category" means authorization can be done by filtering `tools/list` or `allowed_tools` (tool-level).

Reachability caveat. `bloomberg.com`, `reutersagency.com`, `reuters.com`, `dowjones.com`, `factiva.com`, `developer.nytimes.com`, `open-platform.theguardian.com`, `site.financialmodelingprep.com` and `benzinga.com/apis` refused the fetcher used for this research (403 or crawler block). Claims about those providers rest on syndicated copies of their press releases, their GitHub repositories, or third-party directories, and are flagged as such. GitHub star counts and `pushed_at` dates were read from the GitHub REST API on 2026-10-29.

## Key question 1: Does Bloomberg offer an official MCP server, and what do the community BLPAPI wrappers need?

### Takeaway
Yes, since 29 September 2026, but it is an enterprise product with no public endpoint, no free tier and no news content. "Bloomberg Enterprise Model Context Protocol (MCP)" is an AI access layer for Data License Plus (DL+): Bloomberg hosts and manages it, clients' agents connect to it, and every request is checked against the firm's Data License entitlements before data is returned. The press release names pricing and reference data, company fundamentals, economics and alternative data (DL+ Live and the Qube Datastore); it does not mention Bloomberg News, the Terminal, B-PIPE or BLPAPI, and it says a separate solution for Terminal subscribers (tied to ASKB, the Terminal's conversational interface) is forthcoming. Nothing on bloomberg.com offers a signup, URL or GitHub repository. Community MCP servers that wrap BLPAPI exist (the largest has 60 stars and was last pushed April 2025), and every one of them requires a Bloomberg Terminal logged in on the same machine (Desktop API on `localhost:8194`) or a Server API / B-PIPE entitlement; none of those inspected exposes a news tool. Bloomberg is therefore not an option for this lab in any form.

Scope: "more than 100 million securities and over 50,000 fields", pricing and reference data, company fundamentals, economics and alternative data, "spanning DL+ Live and the Qube Datastore (QDS)". Bloomberg "hosts and manages Enterprise MCP, while clients control the AI agents and applications", and Bloomberg "validates a firm's entitlements before returning data on any agent request" under standard Data License rights. Requests resolve against the Operational Datastore and "tool-level limits cap the securities and fields returned per call". Data License clients browse content at data.bloomberg.com. ## Key question 2: Which publishers and wire services offer official MCP servers?

### Takeaway
One wire service does, and it is customer-only: Reuters announced a "Reuters MCP server" for Reuters News Agency customers on 8 July 2026, with no public documentation of URL, auth, tools or category filters. No official MCP server was found for AP, The New York Times, The Guardian, BBC, Financial Times, Dow Jones/Factiva or The Wall Street Journal. The Guardian and NYT have public REST APIs with a section concept and free developer keys (non-commercial), and small community MCP wrappers exist for both; none is hosted.

## Key question 3: Which news API vendors offer MCP servers, with what category shape and free tier?

### Takeaway
Six vendors ship official MCP servers. Only one of them, GNews, is simultaneously hosted, keyed by a static header, free, and category-selectable through an enumerated parameter. NewsData.io's official server is open source and container-ready but not hosted. Event Registry, Perigon and NewsCatcher are hosted but either OAuth-login-only, paid, or without a documented category parameter. World News API is local only. NewsAPI.org, the most-wrapped vendor, has no official server and forbids its free key outside development. Every vendor server is a single tool with a category parameter; none exposes one tool per category.

### Cited Findings
Per vendor (official status, endpoint, auth, tool shape, categories, free tier, demo terms):

- GNews (gnews.io). Official, hosted, `https://mcp.gnews.io/`, streamable HTTP, header `X-Api-Key: <GNews key>`. Registered in the official MCP Registry as `io.github.gnews-io/gnews` (status active, published 2026-10-07, version 1.0.0, repository `gnews-io/gnews-io-mcp-server`). Two tools, read from the server source: `search(q, lang, country, max=10, in_fields, sortby: Literal["publishedAt","relevance"], date_from, date_to, page=1)` and `top_headlines(category: Literal["general","world","nation","business","technology","entertainment","sports","science","health"] = "general", lang, country, max=10, q, date_from, date_to, page=1)`. Resources `docs://gnews/cheatsheet`, `docs://gnews/search`, `docs://gnews/top-headlines`. "Each tool call makes one API request using your key" against the daily quota. Source is a single FastMCP file (`mcp.run(transport="http", host, port, path="/")`), Python, 2 stars, created 2025-10-01, last push 2026-10-07, no LICENSE file (so self-hosting rights are unclear; the hosted endpoint is the intended path). Free plan: 100 requests/day, up to 10 articles per request, 12-hour delay, 30-day history, `content` truncated, CORS localhost only, no card, and "Non-commercial use only"; developing and testing an integration that has not been put into production does not count as commercial. Paid: Essential 49.99 EUR/month (1,000/day), Business 99.99 EUR (5,000/day), Enterprise 249.99 EUR (25,000/day). [MCP docs](https://docs.gnews.io/mcp-server), [registry entry](https://registry.modelcontextprotocol.io/v0/servers?search=gnews), [server.py](https://raw.githubusercontent.com/gnews-io/gnews-io-mcp-server/main/server.py), [pricing](https://gnews.io/pricing)
- NewsData.io. Official, open source, not hosted. Repo `newsdataapi/newsdata.io-mcp`, Python, MIT, 0 stars, created 2026-04-27, last push 2026-09-03; PyPI `newsdata-mcp`; launch blog post 2026-05-12 (updated 2026-08-27). Transports: stdio (`uvx newsdata-mcp`) or `--transport streamable-http --host 127.0.0.1 --port 8000` serving `/mcp`; the README documents `docker run --rm -p 8000:8000 -e NEWSDATA_API_KEY=... newsdata-mcp` for HTTP-mode deployments behind a reverse proxy, so it deploys unmodified to a container host. Auth: `NEWSDATA_API_KEY` environment variable only (no inbound auth on the HTTP endpoint). Tools: `get_latest_news`, `get_archive_news`, `get_crypto_news`, `get_market_news`, `get_news_sources`, `get_news_counts`, `get_crypto_counts`, `get_market_counts`, `register_realtime_query`, `list_realtime_queries`, `delete_realtime_query`, `stream_news`. Category selection: parameter `category` (type `CATEGORY_FILTER`, a list or comma-separated string, up to 5, regex-validated client-side) and `exclude_category` (mutually exclusive with `category`). The 18 accepted codes, from `params.py`: `breaking, business, crime, domestic, education, entertainment, environment, food, health, lifestyle, other, politics, science, sports, technology, top, tourism, world`. Free plan: 200 API credits/day, past 48 hours, 12-hour delay, 1 to 10 articles per credit, crypto and market news included, "For testing & personal projects". Terms (per the vendor subagent's read of newsdata.io/terms): attribution "Powered by NewsData.io API" required, and the API must not be made available over a network to others; a shared MCP deployment sits close to that clause, so check before a public lab. [GitHub](https://github.com/newsdataapi/newsdata.io-mcp), [params.py](https://raw.githubusercontent.com/newsdataapi/newsdata.io-mcp/main/src/newsdata_mcp/params.py), [pricing text on documentation page](https://newsdata.io/documentation), [terms](https://newsdata.io/terms)

Official, hosted at `https://mcp.newsapi.ai/mcp` (streamable HTTP), but the hosted server authenticates by browser OAuth login only ("No download, no API key"); the local server (`npx newsapi-mcp`, stdio or streamable HTTP, Docker image per `docs/deployment.md`) accepts an API key. ## Key question 4: Financial data providers with news by category or topic

### Takeaway
Alpha Vantage has the cleanest official remote MCP with a topic-enumerated news tool (`NEWS_SENTIMENT`, `topics` with 15 values), but the documentation now marks that function Premium, so the free key (25 requests/day) does not cover it. Finnhub's REST market-news endpoint has a four-value `category` enum (general, forex, crypto, merger) and a free tier, but Finnhub has no official MCP server; two small community servers wrap it, one of them container-ready. Massive (ex Polygon.io) rewrote its official server to three generic tools, so it no longer has a news tool. Twelve Data and EODHD have official remote servers with company-news tools and no category parameter. FMP and Benzinga advertise official servers whose pages blocked the fetcher.

### Cited Findings
- Alpha Vantage. Official remote `https://mcp.alphavantage.co/mcp` (streamable HTTP; connecting opens a page where you authorize your API key; the legacy `?apikey=` form is marked deprecated). Local: `uvx marketdata-mcp-server YOUR_API_KEY`. Tools are named after REST functions; news is the single tool `NEWS_SENTIMENT` in the `alpha_intelligence` group. REST `topics` (comma-separated, all must match): `blockchain, earnings, ipo, mergers_and_acquisitions, financial_markets, economy_fiscal, economy_monetary, economy_macro, energy_transportation, finance, life_sciences, manufacturing, real_estate, retail_wholesale, technology`; other parameters `tickers`, `time_from`, `time_to` (`YYYYMMDDTHHMM`), `sort` (`LATEST`, `EARLIEST`, `RELEVANCE`), `limit` (50, max 1000). The documentation section header reads "Market News & Sentiment Trending Premium" and the section ends with "Tip: this is a premium API function. Subscribe to a premium membership plan to instantly unlock all premium APIs." (read from the documentation HTML on 2026-10-29). Free key: "25 API requests per day and unlimited API requests for verified open-source or educational projects". Repo `alphavantage/alpha_vantage_mcp`, Python, MIT, 223 stars, last push 2026-10-03, AWS SAM templates, no Docker instructions. [README](https://raw.githubusercontent.com/alphavantage/alpha_vantage_mcp/main/README.md), [documentation](https://www.alphavantage.co/documentation/), [support](https://www.alphavantage.co/support/)

## Key question 8: Top candidates in detail

### 1. GNews official hosted server (recommended)
- Endpoint: `https://mcp.gnews.io/` (streamable HTTP, served at path `/`). Auth: header `X-Api-Key: <GNews API key>` (free key from https://gnews.io/register, no card).
- Tools (from the published `server.py`, 2026-10-07):
  - `search(q: str, lang: str | None, country: str | None, max: int = 10, in_fields: str | None, sortby: "publishedAt" | "relevance" = "publishedAt", date_from: str | None, date_to: str | None, page: int = 1)`
  - `top_headlines(category: "general" | "world" | "nation" | "business" | "technology" | "entertainment" | "sports" | "science" | "health" = "general", lang, country, max: int = 10, q: str | None, date_from, date_to, page: int = 1)`
- Category list (9): general, world, nation, business, technology, entertainment, sports, science, health.
- Shape: single tool with a `category` parameter (plus a free-text `search` tool that bypasses categories entirely; a restricted agent must be denied `search` or have its queries filtered).
- Free tier: 100 requests/day per key (shared by every agent using that key), 10 articles per request, 12-hour delay, 30-day history, truncated `content`, "Non-commercial use only". A public training lab is non-commercial; a vendor demo at a paying customer is a grey area, so a paid Essential plan (49.99 EUR/month, 10-day trial) is the safe path for commercial use.
- Maintenance: official registry listing published 2026-10-07; repository last push 2026-10-07; docs footer 2026.
- Foundry fit: a key-based project connection (`--auth-type custom-keys --custom-key "X-Api-Key=<key>"`) and an MCP tool with `server_url: https://mcp.gnews.io/`; `allowed_tools` can limit agent B to `top_headlines` only, and the category restriction has to be enforced in front of the server (APIM policy on `tools/call` arguments), as covered in the sibling notes under `research_notes/Foundry agent MCP access control options/`.
- Risks: no licence file on the server repo (irrelevant for hosted use); single maintainer; the hosted server records anonymised usage telemetry (PostHog) including the `category` argument.

### 2. NewsData.io official server, self-deployed unmodified
- Deployment: `docker run --rm -p 8000:8000 -e NEWSDATA_API_KEY=<key> newsdata-mcp` (build from the MIT repo, or `uvx newsdata-mcp --transport streamable-http --host 0.0.0.0 --port 8000`), which serves `/mcp`. Container Apps or App Service can run it as-is; no code change is needed. The endpoint has no inbound auth, so put it behind APIM or a private network.
- Tools: `get_latest_news`, `get_archive_news`, `get_crypto_news`, `get_market_news`, `get_news_sources`, three count tools, four real-time tools. Category parameter: `category` (list or CSV, up to 5) and `exclude_category` on the news tools; `get_news_sources` also filters by category.
- Category list (18): breaking, business, crime, domestic, education, entertainment, environment, food, health, lifestyle, other, politics, science, sports, technology, top, tourism, world.
- Shape: single tool with a `category` parameter; the split into `get_latest_news`, `get_crypto_news` and `get_market_news` gives a coarse tool-level axis (crypto and market news as separate tools) on top of the argument-level one.
- Free tier: 200 credits/day, 48-hour lookback, 12-hour delay, 10 articles per credit. Terms: attribution required; the clause against making the API available over a network to others should be read before exposing the server to a class.
- Maintenance: created 2026-04-27, last push 2026-09-03, CI badge, MIT, 0 stars (vendor-owned, so stars understate backing).

### 3. Finnhub market news via `cyanheads/finnhub-mcp-server`, self-deployed unmodified
- Deployment: image `ghcr.io/cyanheads/finnhub-mcp-server` (HTTP transport and stateless sessions by default, port 3010, path `/mcp`), env `FINNHUB_API_KEY`; optional `MCP_AUTH_MODE=jwt|oauth` gives inbound auth without code changes.
- Tool: `finnhub_get_news(mode: "company" | "market", symbol?, category?: "general" | "forex" | "crypto" | "merger", limit: 1..100 = 15, from?, to?)`; resource `finnhub://news-categories`.
- Category list (4): general, forex, crypto, merger (Finnhub REST `/news?category=`).
- Shape: single tool with a `category` parameter (and `mode`).
- Free tier: Finnhub free key, 60 calls/minute, personal and non-commercial (third-party sources; finnhub.io pricing page not readable). Community server: Apache-2.0, last push 2026-10-07, 1 star, single maintainer with several similar servers.
- Fit: finance flavour, tiny category set, cleanest container story; weakest on "maintained by many" and on the vendor's own terms.

### 4. Apify `automation-lab/google-news-scraper` through `mcp.apify.com`
- Endpoint: `https://mcp.apify.com?tools=automation-lab/google-news-scraper`, `Authorization: Bearer <APIFY_TOKEN>`; the Actor runs as one tool whose input includes `topic` in WORLD, NATION, BUSINESS, TECHNOLOGY, ENTERTAINMENT, SPORTS, SCIENCE, HEALTH, plus `queries`, `country`, `language`, `maxArticles`, `publishedAfter`.
- Shape: single tool with a `topic` parameter; `?tools=` gives platform-level tool restriction per URL, and two different URLs (one per agent) can expose different tool sets, but not different topic sets.
- Cost: Free plan 5 USD/month credit; about 0.24 USD per 100 articles; scraping Google News is a terms-of-service grey area on Google's side.
- Maintenance: Apify platform is well maintained; the Actor is community-built (752 users).

### 5. Pipeworx `country-news` hosted, keyless
- Endpoint: `https://gateway.pipeworx.io/country-news/mcp` (streamable HTTP), anonymous 50 calls/day, free account key (Bearer) 200/day. Tool `country_news(country [required], topic?, language?, query?, days=2, limit=20)`, topic in WORLD, NATION, BUSINESS, TECHNOLOGY, ENTERTAINMENT, SPORTS, SCIENCE, HEALTH (description-only, no schema enum). Google News RSS backend, MIT, created 2026-09-14, last push 2026-10-29, 0 stars.
- Fit: the only keyless hosted option with a category selector; too young and too small to anchor a lab, and the full gateway URL exposes 1,856 other packs' tools.

### Also considered and set aside
- Alpha Vantage `NEWS_SENTIMENT(topics=...)` over `https://mcp.alphavantage.co/mcp`: ideal shape and 15 topics, but the function is Premium (49.99 USD/month and up), and the hosted auth is an OAuth consent page rather than a static header, which does not map onto a Foundry key-based connection.
- Event Registry `https://mcp.newsapi.ai/mcp`: hosted and free-tier, but OAuth-login-only on the hosted endpoint and categories are URIs resolved in a second call.
- Pipedream / Composio NewsAPI wrappers: clean category enum, but the underlying NewsAPI.org free key is development-only, and Pipedream's bearer token rotates.
- Perigon: hosted with 15 REST categories, no free commercial plan.
- Hacker News servers: the only one-tool-per-category server (`paabloLC/mcp-hacker-news`) is stdio-only and unmaintained since June 2025; `cyanheads/hn-mcp-server` is current and container-ready but its type selector is an argument; neither is "news by category" in the sense a business audience expects.

## Key question 9: Recommendation and tool-shape conclusion

### Takeaway
Use the GNews official hosted server (`https://mcp.gnews.io/`, header `X-Api-Key`). It is the only server found that is official, remote over streamable HTTP, authenticated by a static header that fits a Foundry key-based connection, free, listed in the official registry this month, and category-selectable through a nine-value enum on `top_headlines`. If the free plan's non-commercial clause or the 100 calls/day shared budget is a problem, the second choice is the NewsData.io official server deployed unmodified from its MIT repo to Azure Container Apps (200 credits/day, 18 categories, streamable HTTP on `/mcp`); it adds inbound-auth and terms work but keeps the "unmodified third-party code" property. Finnhub via `cyanheads/finnhub-mcp-server` is a third choice if a finance-only, four-category story is acceptable.

### Tool shape
- Every official news-vendor server found (GNews, NewsData.io, Event Registry, Perigon, NewsCatcher, World News API, Alpha Vantage) is a SINGLE TOOL WITH A CATEGORY PARAMETER. So are all the maintained community servers (Google News, NewsAPI.org, Finnhub, Guardian, NYT wrappers) and both aggregator-platform wrappers (Pipedream, Composio, Apify). Per-agent category restriction therefore needs argument-level authorization: a gateway policy that reads `params.arguments.category` on `tools/call` and rejects or rewrites it for agent B. Foundry's own `allowed_tools` cannot express it.
- ONE TOOL PER CATEGORY exists only for Hacker News story types (`paabloLC/mcp-hacker-news`: `getTopStories`, `getNewStories`, `getBestStories`, `getAskHNStories`, `getShowHNStories`, `getJobStories`; stdio only, last push 2025-06-09). NewsData.io gives a partial version (separate `get_latest_news`, `get_crypto_news`, `get_market_news` tools) and Dappier's per-vertical data models are a similar idea behind one tool.
- If the lab wants to show tool-level authorization against a real news source without modifying anyone's server, the honest route is APIM's "REST API as MCP server" over the GNews or NewsData REST API with one operation per category (each operation hard-codes `category=`), which yields one MCP tool per category. That makes the third party the REST API rather than an MCP server, and it should be presented as such.
